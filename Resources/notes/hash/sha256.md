# SHA-256

> Hash 256-bit, khối 64 byte, 64 vòng, **big-endian**, dùng bảng 64 hằng K (căn bậc ba của số nguyên tố).

## 1. Dấu hiệu nhận biết

- **8 hằng khởi tạo**: `0x6A09E667` (`1779033703`), `0xBB67AE85`, `0x3C6EF372`, `0xA54FF53A`, `0x510E527F`, `0x9B05688C`, `0x1F83D9AB`, `0x5BE0CD19`.
- **Bảng K 64 từ**: bắt đầu `0x428A2F98` (`1116352408`), `0x71374491`, `0xB5C0FBCF`, `0xE9B5DBA5` … kết thúc `0xC67178F2`. Trong binary là mảng 256 byte dễ thấy trong `.rdata` (`SHA256_K`).
- **Các phép xoay đặc trưng**:
  - Mở rộng: `σ0 = ROR(x,7) ^ ROR(x,18) ^ (x >> 3)`, `σ1 = ROR(x,17) ^ ROR(x,19) ^ (x >> 10)`.
  - Nén: `Σ1(e) = ROR(e,6) ^ ROR(e,11) ^ ROR(e,25)`, `Σ0(a) = ROR(a,2) ^ ROR(a,13) ^ ROR(a,22)`.
  - Tổ hợp **`7, 18, 3`**, **`17, 19, 10`**, **`6, 11, 25`**, **`2, 13, 22`** là chữ ký (IDA: `__ROR4__(x, 7)` … hoặc `_rotr`).
- Hàm `Ch = (e & f) ^ (~e & g)`, `Maj = (a & b) ^ (a & c) ^ (b & c)`.
- Mảng `w[64]`: 16 từ đầu đọc **big-endian**, từ 16..63 sinh bằng `w[i-16] + σ0 + w[i-7] + σ1`.
- Padding như SHA-1 (`0x80`, độ dài bit big-endian 8 byte); đầu ra 8 từ ghi **big-endian** (32 byte).

## 2. Thuật toán (mã giả)

```
H = [6a09e667 bb67ae85 3c6ef372 a54ff53a 510e527f 9b05688c 1f83d9ab 5be0cd19]
for mỗi khối: w[0..15] = BE words
    for i in 16..63: w[i] = w[i-16] + σ0(w[i-15]) + w[i-7] + σ1(w[i-2])
    a..h = H
    for i in 0..63:
        t1 = h + Σ1(e) + Ch(e,f,g) + K[i] + w[i]
        t2 = Σ0(a) + Maj(a,b,c)
        h=g; g=f; f=e; e=d+t1; d=c; c=b; b=a; a=t1+t2
    H += (a..h)
digest = H big-endian
```

## 3. Mã hóa / giải mã

Không đảo ngược. Dùng cho check flag (so sánh `SHA256(input)` với hằng 32 byte), sinh khóa (AES-256 key = `SHA256(password)`), PoW. Nếu input có cấu trúc (hex/độ dài nhỏ) thì brute force; nếu không thì phải tìm nguồn của input (key sinh từ file khác…).

```c
void sha256_hash(const uint8_t *msg, size_t n, uint8_t out[32])
{
    uint8_t buf[320];
    uint32_t H[8];
    size_t total = ((n + 8) / 64 + 1) * 64;
    uint64_t bits = (uint64_t)n * 8;
    for (int i = 0; i < 8; i++) H[i] = SHA256_H0[i];
    memset(buf, 0, sizeof(buf));
    memcpy(buf, msg, n);
    buf[n] = 0x80;
    for (int i = 0; i < 8; i++) buf[total - 1 - i] = (uint8_t)(bits >> (8 * i));
    for (size_t off = 0; off < total; off += 64) {
        uint32_t w[64];
        for (int i = 0; i < 16; i++)
            w[i] = ((uint32_t)buf[off + 4 * i] << 24) | ((uint32_t)buf[off + 4 * i + 1] << 16) |
                   ((uint32_t)buf[off + 4 * i + 2] << 8) | buf[off + 4 * i + 3];
        for (int i = 16; i < 64; i++) {
            uint32_t s0 = ROR32(w[i - 15], 7) ^ ROR32(w[i - 15], 18) ^ (w[i - 15] >> 3);
            uint32_t s1 = ROR32(w[i - 2], 17) ^ ROR32(w[i - 2], 19) ^ (w[i - 2] >> 10);
            w[i] = w[i - 16] + s0 + w[i - 7] + s1;
        }
        uint32_t a = H[0], b = H[1], c = H[2], d = H[3], e = H[4], f = H[5], g = H[6], h = H[7];
        for (int i = 0; i < 64; i++) {
            uint32_t S1 = ROR32(e, 6) ^ ROR32(e, 11) ^ ROR32(e, 25);
            uint32_t ch = (e & f) ^ (~e & g);
            uint32_t t1 = h + S1 + ch + SHA256_K[i] + w[i];
            uint32_t S0 = ROR32(a, 2) ^ ROR32(a, 13) ^ ROR32(a, 22);
            uint32_t maj = (a & b) ^ (a & c) ^ (b & c);
            uint32_t t2 = S0 + maj;
            h = g; g = f; f = e; e = d + t1; d = c; c = b; b = a; a = t1 + t2;
        }
        H[0] += a; H[1] += b; H[2] += c; H[3] += d; H[4] += e; H[5] += f; H[6] += g; H[7] += h;
    }
    for (int i = 0; i < 8; i++) {
        out[4 * i] = (uint8_t)(H[i] >> 24); out[4 * i + 1] = (uint8_t)(H[i] >> 16);
        out[4 * i + 2] = (uint8_t)(H[i] >> 8); out[4 * i + 3] = (uint8_t)H[i];
    }
}
```

## 7. Biến thể & bẫy

- **SHA-224**: cùng thuật toán, hằng khởi tạo khác, cắt còn 28 byte. **SHA-384/512**: xem [sha512.md](sha512.md).
- **Double SHA-256** (Bitcoin): `SHA256(SHA256(x))`.
- **HMAC-SHA256**, **PBKDF2-HMAC-SHA256**: số vòng lặp lớn (`1000/10000`), có `0x36`/`0x5C`.
- Ở hash tuỳ biến: đổi vòng xoay hoặc đổi vài hằng K → không khớp `hashlib`, cần tái hiện.
